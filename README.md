# Overview
This repository hosts the source code of the Task Manager application, which is the use case for the Classicist TDD, the Outside-In TDD, and TDD with AI sections.

# Branches
There are 7 branches in total. Except for the `master` branch, there's one branch for the starting point and the solution of each section:
* [`classicist-starting-point`](https://github.com/nvoulgaris/tdd-in-action-demo-app/tree/classicist-starting-point)
* [`classicist-tdd-solution`](https://github.com/nvoulgaris/tdd-in-action-demo-app/tree/classicist-tdd-solution)
* [`outside-in-tdd-starting-point`](https://github.com/nvoulgaris/tdd-in-action-demo-app/tree/outside-in-tdd-starting-point)
* [`outside-in-tdd-solution`](https://github.com/nvoulgaris/tdd-in-action-demo-app/tree/outside-in-tdd-solution)
* [`tdd-with-ai-starting-point`](https://github.com/nvoulgaris/tdd-in-action-demo-app/tree/tdd-with-ai-starting-point)
* [`tdd-with-ai-solution`](https://github.com/nvoulgaris/tdd-in-action-demo-app/tree/tdd-with-ai-solution)
